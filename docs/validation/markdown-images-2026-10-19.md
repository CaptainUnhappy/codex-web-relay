# 助手回复中的本地 Markdown 图片

日期：2026-10-19。

## 问题与修复

此前只有附件会登记图片预览 ID；助手回复中的 `![说明](/C:/.../image.png)` 没有经过登记，前端也没有 Markdown 图片渲染分支，因此直接显示源文本。

- 历史消息、实时预览、最终回复及助手进度文字统一登记本地图片，转换为不包含文件路径的 `codex-image:` 引用，再由前端接入已有图片查看器。
- 支持绝对本地路径、`/C:/` 形式、`file:` URL、空格、中文及括号。图片保持比例，点击可预览、缩放和关闭。
- 用户消息正文和工具输出不会据此登记文件；代码中的图片示例保持原样。原始聊天记录不改写。
- 复用已有认证图片接口、不可猜测 ID、文件类型检测和 20 MiB 限制。未新增可由浏览器传入任意文件路径的接口，UNC、SVG 和非图片文件仍不支持。
- 缓存保留预览 ID，不保存带认证参数的图片地址。服务重启后需刷新历史取得新 ID；原文件被移除时显示无法加载。
