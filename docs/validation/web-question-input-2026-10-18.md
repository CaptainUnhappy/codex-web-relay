## 根因与修改

旧页面只支持 Mini 自己收到的原生 `item/tool/requestUserInput`，没有读取桌面端的异步提问。桌面端把这类问题持久化为 `event_msg / item_completed / AgentMessage`，其中 `delivery` 为 `async`，`questions` 保存题目和选项；当前原生历史摘要未完整提供这些字段。

另一个问题是历史回答中的 `<send_user_message_question_reply>` 协议包装被直接显示，用户看到的是内部数据。

本次增加按选中会话读取的提问适配：只读最近 5 MiB 日志，按文件大小和修改时间缓存；问题支持 Markdown、选项和自定义回答。服务端校验问题与会话归属，并沿用原生发送和队列流程。历史协议包装转换成可读的提问和回答。固定请求标识、队列检查与不确定结果保护防止重复提交；独立审批查询也检查原生队列，避免服务重启后重新显示可提交按钮。
